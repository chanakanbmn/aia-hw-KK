ข้อควรระวัง
- หุ้นแตก 10:1 ต.ค. 2024: ไม่เทียบ EPS หรือจำนวนหุ้นข้ามฐาน ตาราง 5 ปีใช้ยอดรวมเป็นดอลลาร์ · FY2024 ยาว 53 สัปดาห์
- แก้ตามผลตรวจ (2026-11-03): ฉากฐานปรับเป็นโต +8%/ปี (รายได้ปี 2029 ไม่ต่ำกว่ารายได้ไตรมาสล่าสุด x 4) มูลค่าสามฉากต่อหุ้น ก่อน/หลังหัก SBC = ดี ~$277/~$267 · ฐาน ~$141/~$133 · แย่ ~$26/~$21 (ฉากแย่ซ้อนมัลติเพิลต่ำสุดกับ margin ต่ำสุด) · ราคาซื้อหุ้นคืน $329.17/$370.15 เป็นของหุ้นซื้อในตลาดไม่รวม ASR (ต้นทุนรวม Q1 FY27 ~$431, ทั้งปี FY2026 ~$148.5) · ราคา 227.56 และ 438.5 เป็นแหล่งรอง Yahoo ยังไม่ยืนยัน
- อัตราคิดลด อัตราโต margin และมัลติเพิลของฉากเป็นสมมติฐานผู้วิเคราะห์ ฉากต่อหุ้นไม่ใช่ราคาเป้าหมาย ไม่มีน้ำหนักความน่าจะเป็น
- เอกสารไม่ระบุสาเหตุที่ราคาหุ้นเปลี่ยน และไม่ให้ตัวเลขดอลลาร์ของผลกระทบข้อจำกัดส่งออก ผู้ถือหุ้นใหญ่ใน DEF 14A เป็นข้อมูลเก่า
- ticker ใช้ป้าย "โซน" เท่านั้น ตรรกะเดียวกับ `src/alert.py` (ราคาเก่าเกิน 7 วัน = ราคาเก่า) ไม่มี API key · ยังไม่ผ่านด่านตรวจเทียบเอกสาร (draft)
