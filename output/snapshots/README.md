# Snapshot คำแนะนำโซนซื้อ

ไฟล์ CSV ภาพนิ่งของคำแนะนำ ณ วันหนึ่ง เก็บไว้เทียบกับราคาจริงและตัวเลขปัจจุบันภายหลัง (เช่น 3 เดือน) **ห้ามแก้ไฟล์ snapshot เดิม** ถ้าสมมติฐานเปลี่ยน ให้สร้าง snapshot ใหม่ของวันนั้น

| ไฟล์ | คืออะไร |
|---|---|
| `2026-11-04.csv` | snapshot แรก: 8 ตัวใน dashboard (NOW, INTU, NTNX, S, KVYO, ZETA, LRCX, BX) |

## เก็บอะไรไว้

วันที่ snapshot · หุ้น · ราคาและวันที่ของราคา · โซน 3/2/1 (ราคาเกณฑ์) · สถานะ · ป้าย (ซื้อ/สนใจ/รอ) · มูลค่าสามฉาก (ถ้ามี) และคำอธิบายว่าเป็นหน่วยอะไร · ระดับ S&P 500 ณ วันนั้น · git commit ที่ใช้ · แหล่งข้อมูล

ไม่เก็บพอร์ต จำนวนหุ้น หรือราคาต้นทุนของผู้ใช้ ราคาจาก Yahoo Finance แบบไม่เป็นทางการ [ยังไม่ยืนยัน]

หมายเหตุหน่วยของสามฉาก: NOW และ LRCX เป็นมูลค่าต่อหุ้นก่อนหัก SBC ตามสมมติฐานผู้วิเคราะห์ (ไม่ใช่ราคาเป้าหมาย) · INTU เป็นมัลติเพิล EV ÷ กำไรจากการดำเนินงาน FY2029 (ดี 9.6 / ฐาน 11.7 / แย่ 19.4 ยิ่งต่ำยิ่งถูก) ไม่ใช่ราคา · BX เป็นมูลค่าต่อหุ้นตาม BX.md · NTNX, S, KVYO, ZETA ไม่มีสามฉาก

## วิธีใช้

สร้าง snapshot ใหม่ (วันนี้) จากรายการใน `output/dashboard/watchlist.json`:

```bash
"D:\Let's go\.venv\Scripts\python.exe" -m src.snapshot create
```

เทียบ snapshot เก่ากับปัจจุบัน (เช่นผ่านไป 3 เดือน) จากโฟลเดอร์ repo:

```bash
"D:\Let's go\.venv\Scripts\python.exe" -m src.snapshot compare output\snapshots\2026-11-04.csv
```

ได้ตารางและไฟล์ `compare-<วัน snapshot>-to-<วันนี้>.md` มี ราคาตอนนั้น/ตอนนี้, ผลตอบแทน, ผลตอบแทน S&P 500 ช่วงเดียวกัน, ส่วนต่าง, ราคาต่ำสุด-สูงสุดในช่วง, สถานะตอนนั้นเทียบตอนนี้ (ใช้โซนที่ล็อกไว้ใน snapshot ไม่คำนวณใหม่) และวันที่ราคาเข้าโซน 3 และโซน 2 ครั้งแรก

ถ้าต้องการให้ `python -m` ทำงาน ต้องรันจากโฟลเดอร์ repo

## สิ่งที่ต้องตรวจด้วยมือตอนเทียบ

สคริปต์วัดเฉพาะราคา ส่วนต่อไปนี้ต้องเปิดดูเอง:
1. งบจริงที่ออกใหม่ เทียบกับสามฉากที่ตั้งไว้ใกล้ฉากไหน (รายได้โต, FCF, EPS)
2. เงื่อนไขเปลี่ยนใจในโน้ตของแต่ละหุ้น (เช่น NOW cRPO < 18%, gross margin < 70%) เกิดขึ้นหรือยัง
3. S&P 500 ช่วงเดียวกันเป็นตัวเทียบขั้นต่ำ ถ้าหุ้นทำได้ไม่ดีกว่าดัชนี โซนนั้นยังไม่ได้พิสูจน์อะไร

## ข้อจำกัด

- ช่วงสั้นและมีหุ้นไม่กี่ตัว ผลเป็นบทเรียน ไม่ใช่ข้อพิสูจน์ว่าโซนใช้ได้ ควรบันทึกทั้งตัวที่โซนพลาดด้วย
- "เข้าโซน" นับจากราคาปิดรายวัน ไม่ใช่ราคาระหว่างวัน
- ราคาแหล่งรองอาจถูกแก้ย้อนหลัง
- โซนของแต่ละหุ้นมาจากกฎเทียบอดีตของตัวเอง ไม่ใช่คำแนะนำลงทุน
- snapshot ไม่ใช่ backtest: คำแนะนำนี้ทำขึ้นวันนี้ แล้วรอดูผลไปข้างหน้า (forward test) จึงไม่มีอคติจากการรู้ผลล่วงหน้า แต่ต้องรอเวลา
