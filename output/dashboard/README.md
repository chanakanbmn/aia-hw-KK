# Watchlist Dashboard

หน้าเดียวเรียงรายการหุ้นที่สนใจ: ชื่อหุ้น · ราคาปัจจุบัน · โซน valuation · สี · ป้าย ซื้อ/สนใจ/รอ · ปุ่มดู infographic

## วิธีรัน

จากโฟลเดอร์ repo:

```
"D:\Let's go\.venv\Scripts\python.exe" -I output\dashboard\server.py
```

แล้วเปิด http://127.0.0.1:8770 กด "เปิดการแจ้งเตือน" หนึ่งครั้ง จากนั้นเปิดแท็บทิ้งไว้ หน้าจะรีเฟรชทุก 5 นาที และเตือนเมื่อป้ายของหุ้นตัวใดเปลี่ยน

## เปิดให้คนอื่นดู (หน้านิ่ง)

dashboard ที่รันด้วย `server.py` ฟังเฉพาะในเครื่องคุณ คนอื่นเปิดไม่ได้ ถ้าจะแชร์ให้สร้างหน้านิ่ง:

```bash
"D:\Let's go\.venv\Scripts\python.exe" -I output\dashboard\build_static.py
```

ได้ `output/dashboard/public.html` (ฝังข้อมูล ณ เวลาที่รัน เปิดได้โดยไม่ต้องมีเซิร์ฟเวอร์) และ `index.html` ที่รากของ repo ที่พาไปหน้านั้น เมื่อเปิด GitHub Pages (Settings → Pages → Branch `main` โฟลเดอร์ `/ (root)`) ลิงก์จะเป็น `https://chanakanbmn.github.io/aia-hw-KK/`

ข้อควรรู้ของหน้านิ่ง:
- เป็นภาพนิ่ง ณ เวลาที่รัน ไม่ใช่ราคาสด ต้องรันสคริปต์ใหม่และ push เมื่ออยากอัปเดต (เวลาที่ข้อมูลถูกดึงแสดงบนแถบประกาศ)
- แถบประกาศบนหัวหน้าเขียนว่าราคาเป็นแหล่งรอง [ยังไม่ยืนยัน] และไม่ใช่คำแนะนำลงทุน
- ไม่มีปุ่มรีเฟรช/แจ้งเตือน และหน้ามี Content-Security-Policy ที่ห้ามเชื่อมต่อเครือข่ายทุกชนิด ไม่ดึงข้อมูลจากที่ไหนตอนเปิด
- ปุ่ม infographic เป็นลิงก์สัมพัทธ์ไปไฟล์ใน `output/<หุ้น>/`
- ราคาจาก Yahoo Finance แบบไม่เป็นทางการ การเผยแพร่สาธารณะอาจขัดเงื่อนไขของ Yahoo ควรอ่านเงื่อนไขก่อนเผยแพร่

## จัดกลุ่มตาม sector

หุ้นถูกจัดเป็นกลุ่มตาม `sector` ใน `watchlist.json` (ตอนนี้: "ซอฟต์แวร์ / ไซเบอร์" 6 ตัว, "เซมิคอนดักเตอร์ (อุปกรณ์ผลิตชิป)" 1 ตัว คือ LRCX และ "การเงิน (Alternative Asset)" 1 ตัว) หัวกลุ่มแสดงจำนวนหุ้นและสรุปป้าย (ซื้อ/สนใจ/รอ) กดที่หัวกลุ่มเพื่อพับ/ขยาย สถานะพับจำในเบราว์เซอร์นี้
จะเพิ่ม sector ใหม่ ให้ใส่ `"sector": "ชื่อกลุ่ม"` ในหุ้นแต่ละตัว หุ้นที่ชื่อกลุ่มเดียวกันจะอยู่ด้วยกัน ลำดับกลุ่มตามลำดับที่ปรากฏในไฟล์ และหุ้นในกลุ่มเรียง ซื้อ → สนใจ → รอ → ไม่มีข้อมูล หุ้นที่ไม่ใส่ sector จะอยู่กลุ่ม "อื่น ๆ"

## หน้าตา

- พื้นหลังของแต่ละแถวเปลี่ยนสีตามโซนปัจจุบัน: โซน 3 เขียว · โซน 2 เหลือง · โซน 1 ส้ม · นอกโซน แดง · ไม่มีข้อมูล เทา
- ใต้ชื่อหุ้นมีแถบโซน (ความกว้างตามสัดส่วนราคา) และ ▲ ชี้ตำแหน่งราคาปัจจุบัน
- ต่อท้ายราคามี sparkline ราคาปิดรายวัน 3 เดือน (เส้นเขียวถ้า 3 เดือนขึ้น แดงถ้าลง) พร้อม % เปลี่ยนแปลง

## กฎป้าย

| ป้าย | สี | สถานะ |
|---|---|---|
| ซื้อ | เขียว | โซน 3 (ล่างสุดราว 5% ของช่วงมัลติเพิลในอดีตของหุ้นตัวเอง) |
| สนใจ | เหลือง | โซน 2 (ราว 15%) |
| รอ | แดง | โซน 1 หรือนอกโซน |
| - | เทา | ไม่มีราคา / ราคาเก่าเกิน 7 วัน / ไม่มีโซน |

BX ใช้โซนจาก margin of safety ใน `../BX/BX.md` (≤ buy_max = ซื้อ, ≤ hold_max = สนใจ) INTU ใช้โซนฐาน FCF ปรับภาษี

## เพิ่ม/ลบหุ้น

แก้ `watchlist.json` ใส่ `zones_file` (ไฟล์โซนของหุ้นตัวนั้น) หรือใส่ `zone3_max`, `zone2_max`, `zone1_max` ตรง ๆ และ `infographic` ถ้ามี

## ความเป็นส่วนตัวและความปลอดภัย

- เซิร์ฟเวอร์ฟังเฉพาะ 127.0.0.1 เครื่องอื่นในเครือข่ายเข้าไม่ได้ ไม่มี token ไม่มีบัญชี
- ข้อมูลที่ออกจากเครื่องมีแค่คำขอราคาไป Yahoo Finance สำหรับหุ้นใน `watchlist.json` เท่านั้น
- ไม่เก็บพอร์ต จำนวนหุ้น หรือราคาต้นทุน ป้ายล่าสุดเก็บใน localStorage ของเบราว์เซอร์เครื่องนี้
- เสิร์ฟเฉพาะหน้า dashboard และ infographic ที่อยู่ใน watchlist ไฟล์อื่นตอบ 404
- ใช้ไลบรารีมาตรฐานของ Python ไม่ติดตั้งอะไรเพิ่ม หน้าเว็บไม่โหลดสคริปต์หรือฟอนต์จากภายนอก

## ข้อจำกัด

- เตือนเฉพาะตอนเปิดหน้าไว้
- ป้ายมาจากกฎโซนเทียบอดีตของหุ้นตัวเอง ไม่ได้รวมคุณภาพธุรกิจหรือข่าว ต้องอ่าน infographic ประกอบ
- ราคา Yahoo เป็นแหล่งไม่เป็นทางการ [ยังไม่ยืนยัน] อาจล่าช้าหรือใช้ไม่ได้ชั่วคราว
- ไม่ใช่คำแนะนำลงทุน
